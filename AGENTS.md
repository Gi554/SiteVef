# Travail sur ce dépôt

- Créer une branche dédiée pour chaque changement, puis ouvrir une pull request vers `version1`.
- Ne jamais pousser de nouveaux commits directement sur `version1` et ne pas fusionner les pull requests sans demande explicite de l’utilisateur.
- Découper le travail en commits cohérents, avec des messages en français expliquant le changement et sa raison. Le projet est aussi maintenu par un développeur junior.
- Ne pas ajouter de dossier ChatGPT, de fichiers `.env`, de clés, de dépendances installées ou d’aperçus générés dans Git.
